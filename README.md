# 🍳 Τι τρώμε σήμερα;

Το site που προτείνει τι να μαγειρέψετε, χωρίς να επαναλαμβάνεστε.

## Τι κάνει
- **🎲 Σήμερα**: 4 ιδέες (2 ελληνικές + 2 διεθνείς από το [TheMealDB](https://www.themealdb.com)). Με «🙅 Όχι σήμερα» αλλάζει μόνο αυτή η κάρτα. Έχει και το «🪙 Ποιος μαγειρεύει σήμερα;».
- **🧊 Ψυγείο**: γράφεις τι έχεις και σου βγάζει συνταγές, με το τι σου λείπει.
- **📅 Εβδομάδα**: μενού για 7 μέρες. Το «✨ Γέμισέ μου την εβδομάδα» το γεμίζει μόνο του (χωρίς πρόσφατα φαγητά και όχι πάνω από 2 από την ίδια κατηγορία). Με το 🎲 αλλάζεις μία μέρα.
- **🛒 Ψώνια**: η λίστα φτιάχνεται μόνη της από το μενού και αθροίζει ποσότητες (π.χ. 500 γρ. + 600 γρ. κιμάς = 1,1 κιλό). Τσεκάρεις ό,τι πήρες και με το «📋 Αντιγραφή» τη στέλνεις στο Viber.
- **📖 Συνταγές / Τι φάγαμε**: όλες οι συνταγές και το ιστορικό. Ό,τι πατήσετε «Το φάγαμε» δεν ξαναπροτείνεται για 7 μέρες.
- **Φίλτρα** (πάνω πάνω, ισχύουν παντού): «😇 Νηστεύει ο Χρήστος» και «👑 Τρώει και η Νικολέτα».
- **Όλες οι ποσότητες είναι για 4 άτομα.** Στο TheMealDB οι ποσότητες είναι όπως στην αρχική συνταγή (συνήθως 4).

## Αρχεία
| Αρχείο | Τι είναι |
|---|---|
| `index.html` | Η σελίδα |
| `style.css` | Χρώματα και εμφάνιση (τα χρώματα είναι στην αρχή) |
| `config.js` | **Ονόματα, μήνυμα-έκπληξη, ρυθμίσεις Firebase** |
| `recipes.js` | Οι 123 ελληνικές συνταγές. Πρόσθεσε εδώ δικές σας. |
| `store.js` | Αποθήκευση (Firebase ή κινητό) |
| `app.js` | Η λογική. Στην αρχή έχει τα αστεία (`TAGLINES` κ.λπ.) αν θες να βάλεις δικά σας. |

## 💌 Η έκπληξη
Την πρώτη φορά που ανοίγει το site σε ένα κινητό, εμφανίζεται ένα μήνυμα για τη Νικολέτα. Το κείμενο το αλλάζεις στο `config.js` → `surprise`.
**Προσοχή:** εμφανίζεται μία φορά ανά κινητό/browser. Αν το δοκιμάσεις στο δικό σου κινητό, στο δικό της θα εμφανιστεί κανονικά.

---

## Βήμα 1: Ανέβασμα στο GitHub Pages
1. Στο GitHub: **New repository** → όνομα (π.χ. `ti-trwme`) → **Public** → **Create repository**.
2. **uploading an existing file** → σύρε όλα τα αρχεία (`index.html`, `style.css`, `config.js`, `recipes.js`, `store.js`, `app.js`) → **Commit changes**.
3. **Settings → Pages** → Source: **Deploy from a branch** → branch **main**, φάκελος **/ (root)** → **Save**.
4. Σε 1-2 λεπτά: `https://<username>.github.io/ti-trwme/`
5. Στο κινητό: «Προσθήκη στην αρχική οθόνη» για να μοιάζει με εφαρμογή.

Ως εδώ το site δουλεύει, αλλά κάθε κινητό έχει το δικό του ιστορικό και μενού.

## Βήμα 2: Κοινό ιστορικό και μενού με Firebase (δωρεάν)
Έτσι μπαίνετε με Google και βλέπετε και οι δύο τα ίδια. **Μόνο τα δύο email σας** μπορούν να διαβάσουν ή να αλλάξουν τα δεδομένα. Όποιος άλλος βρει το link βλέπει μόνο την οθόνη σύνδεσης.

1. Πήγαινε στο <https://console.firebase.google.com> → **Create a project** → όνομα (π.χ. `ti-trwme`) → μπορείς να κλείσεις το Google Analytics → **Create project**. Το δωρεάν πλάνο (Spark) αρκεί, δεν χρειάζεται κάρτα.
2. **Authentication**: αριστερά **Build → Authentication → Get started** → καρτέλα **Sign-in method** → **Google** → **Enable** → διάλεξε το email σου ως support email → **Save**.
3. Στο ίδιο μέρος: **Settings → Authorized domains → Add domain** → γράψε `<username>.github.io` (το δικό σου username) → **Add**.
4. **Βάση**: **Build → Firestore Database → Create database** → τοποθεσία `eur3 (europe-west)` → **Start in production mode** → **Create**.
5. Στη Firestore πήγαινε στην καρτέλα **Rules**, σβήσε ό,τι έχει και βάλε αυτό, με **τα δικά σας email**:
   ```
   rules_version = '2';
   service cloud.firestore {
     match /databases/{database}/documents {
       match /homes/{homeId} {
         allow read, write: if request.auth != null
           && request.auth.token.email in ['christos@gmail.com', 'nikoleta@gmail.com'];
       }
     }
   }
   ```
   → **Publish**.
6. **Σύνδεση με το site**: ⚙️ (πάνω αριστερά) → **Project settings** → κάτω στο **Your apps** πάτα το εικονίδιο **</>** (Web) → ψευδώνυμο (π.χ. `site`) → **Register app**. Θα σου δείξει ένα `firebaseConfig = { ... }`.
7. Άνοιξε το `config.js` και αντέγραψε τις τιμές `apiKey`, `authDomain`, `projectId`, `appId` στις αντίστοιχες θέσεις, μέσα στα εισαγωγικά.
8. Ανέβασε ξανά το `config.js` στο GitHub. Τέλος!

Πρώτη φορά που θα μπει ο καθένας, πατάει «Σύνδεση με Google». Ό,τι υπήρχε ήδη στο κινητό του πρώτου που συνδέεται ανεβαίνει αυτόματα στη βάση.

**Είναι ασφαλές που το `apiKey` φαίνεται στο GitHub;** Ναι. Στο Firebase αυτό το κλειδί δεν είναι μυστικό. Την προστασία την κάνουν τα Rules του βήματος 5.

## Μικρές αλλαγές που ίσως θέλεις (στο `app.js`)
- `BLOCK_DAYS` / `FRESH_DAYS`: πόσο αυστηρή είναι η αποφυγή επανάληψης.
- `FILTERS`: τι κόβει κάθε φίλτρο.
- `TAGLINES`, `THINKING`, `WHO_COOKS`: τα αστεία.
